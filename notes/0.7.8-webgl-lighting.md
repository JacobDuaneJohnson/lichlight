# v0.7.8 draft — hybrid WebGL2 lighting

Not a release. `VERSION` in `index.html` stays `0.7.7` until `release.sh` bumps it. Do not tag, merge, or publish to GitHub Pages from this branch.

## What plays

The world, particles, sprites, and UI still draw on the Canvas 2D context (`ctx` / `#game`). Lighting is the only part that can leave that context.

Each frame, after the world draw and before emissive sprites:

1. `gatherLights` builds the same light list as before (`frameLights`). `lightAt` (eyes in the dark, dust motes) still tests those polygons in JS.
2. **WebGL2 path** when all of these are true:
   - GL LIGHT is `AUTO` or `ON` (pause / title menu)
   - Lighting quality is **High** (Low always stays on the Canvas lightmap)
   - `webgl2` exists and the shader linked
3. Otherwise the existing `lcan` lightmap is filled and multiplied over the scene, including half-resolution on Low.

The shader writes a light image (ambient, explored memory, additive lights, Bayer dither), multiplies it by the 2D scene, then `drawImage`s that result back onto `#game`. `drawEmissive`, bloom, vignette, and the HUD run after that, on `ctx`, so flames, eyes, motes, and sparkles stay above the darkness.

## Toggle

| GL LIGHT | Lighting quality | Result |
| --- | --- | --- |
| AUTO | High | WebGL2 if the context works, else `lcan` |
| ON | High | same as AUTO (ON does not invent a context) |
| OFF | High | Canvas `lcan` |
| any | Low | Canvas `lcan` (half-res) |

Phones auto-pick **Low** (`pointer: coarse`), so an iPhone stays on the Canvas lightmap until Lighting is set to High. GL LIGHT is saved in the same settings object as sound and shake.

Test hooks (not shown in the menu): `window.__noWebGL = true` or `window.__forceCanvasLight = true`.

`game.lightPath()` is `'webgl'` or `'canvas'`. `game.glStatus()` reports init, the packed light count, and the occlusion-mask count.

## Shader

GLSL ES 3.00, no libraries. Fullscreen triangle (`gl_VertexID` only).

Light pass uniforms:

- `uPos[32]`, `uRad[32]` — screen pixels (origin matches the GL framebuffer). Radius is ellipse-scaled with the view so zoom matches `zoomVis`.
- `uCol[32]` — `LCOL` 0–1. `uAmp[32]` — the light's `a`, clamped to 1.
- `uOcc[32]` — mask layer, or `-1` if that light was already unoccluded on the Canvas path (projectiles, item glints, the small flame core).
- `uCount`, `uResolution`, `uView` (world x, y, w, h of `zoomVis`)
- `uAmbient` `#050408`, `uExplored` `#1a1520`, `uSeen` (one texel per map tile), `uTile` (16)
- `uMask` — `sampler2DArray`, R8, nearest. One layer per distinct visibility polygon. Binary union of the raycast (not the Canvas 1/n bands).
- `uPen`, `uSpill`, `uCore`, `uHaze`, `uFill` — the WebGL look. JS source of truth is `GL_LOOK` (`game.glLook()`).

Falloff on this path is not the Canvas gradient. A tight gaussian core mixes the light color toward near-white amber (`1, 0.96, 0.84`). A wider gaussian (`uSpill`, default 1.36× radius) carries the color further. `uHaze` adds a little of the light's own color along that cone. An 8×8 Bayer matrix adds ±0.5/255 so the multiply does not band in 8-bit.

`GL_LOOK` defaults: `penumbra` 12 px, `spill` 1.36, `core` 1, `haze` 0.22, `fill` 0.18. Void RGB `5, 4, 8` (`#050408`). Explored RGB `26, 21, 32` (`#1a1520`).

## Lighting (Dev) panel

Playtest only. There is no menu row on the title or pause screen.

**Gate** (`game.lichDevOn(host, search)`). The HUD sun button and the overlay are created only when this is true:

- host is `githack.com`, `raw.githack.com`, `rawcdn.githack.com`, or any other `*.githack.com`
- host is `localhost`, `127.0.0.1`, or `::1` (headless tests)
- any other host, including `file://`, when the URL has `?lichDev=1`

It is **never** true on `github.io` or `*.github.io`, even with `?lichDev=1`. A normal GitHub Pages release does not mount the button or the panel.

During play the sun button sits at the top left and opens the overlay. The game keeps running underneath. The panel and the backdrop are translucent (about 30% black behind, about 42% on the card) so the lighting shows through. The list scrolls inside the card. Close with ×, Escape, or a tap on the backdrop.

`game.glLook()` is the live object. Reset restores the defaults and clears `localStorage` key `lichlight-gl-look`. WebGL-only rows (penumbra, spill, core, haze, fill, Seen, Void) grey out while the Canvas lightmap is drawing. Rays, bite, band offset, bloom, and the outline keep working on both paths.

Low lighting still uses the smaller bloom cap (8 vs 24) and the weaker base strength. The bloom dials multiply those presets. The panel says which preset is active.

Composite pass: `uScene` (the 2D canvas, nearest, re-uploaded each frame, resized only when `VW`/`VH` change) times `uLight`.

## Occlusion

Major lights still carry `poly` / `polys` from `visPoly` / `bandPolys`. The Canvas path still draws those bands at `1/n` (`drawLightPolys`). The WebGL path does not:

- The mask is a **binary union** of the same polygons (full white inside, empty outside).
- `softCover` returns 0 when the center sample is outside, so a blur cannot paint the next room.
- Inside the mask, eight taps one `penumbra` away (default 12 px) fade coverage with `smoothstep`. The shadow edge melts instead of stepping 100 / 75 / 50 / 25.
- Lights that share one polygon array share one layer.
- Cap is 24 masks and 32 lights (the uniform budget on a minimum WebGL2 device). Past that, extra **occluded** lights are dropped, not drawn through walls. Extra unoccluded lights past 32 are dropped (the dimmest first). Occluded lights are packed first. The Canvas path has no cap.

Masks stay nearest-filtered. The penumbra only darkens pixels that are already inside the raycast.

## Room fill

After the direct light, an occluded light adds `uFill` on **explored** floor (`uSeen`) weighted by the same softened mask. Unexplored tiles do not get the bounce (they can still take direct light if the raycast reaches them). Pixels outside the mask get neither. Unlit explored floor stays near `#1a1520`. Unlit unexplored stays near `#050408`.

## Fallback

WebGL2 missing, shader compile/link failure, context loss, or a framebuffer that will not complete: that frame uses `lcan` and the reason is kept on `glStatus().reason`. A lost context stays on Canvas until the browser restores it. `preserveDrawingBuffer` is on so the copy back onto the 2D canvas is reliable in Safari; that is an extra fullscreen copy.

## Known gaps

- Low quality never uses the shader, by decision. iPhone default is Low.
- The shader is not a byte match of `LGRAD`. ON vs OFF on High is supposed to look different: soft edge, hot core, longer color, a bit of room fill. Canvas keeps the banded gradient.
- Unoccluded lights (shots, ground glints, the tiny flame core) can still cross a wall. That is the same as `lcan` today.
- If more than 24 occluded lights are on screen, the extras go dark instead of bleeding.
- No WebGL half-resolution mode. High is full internal resolution (`VW`×`VH`, already a small pixel grid).
- Desktop and iPhone Safari still need a human playtest before merge. This branch was checked with headless Chrome only.

## Playtest (desktop + iPhone Safari)

1. New game, Lighting **High**, GL LIGHT **ON**. The torch core should read hotter (near-white amber) than the Canvas gradient, color should carry further across the floor, and the shadow on a wall should melt instead of showing three or four hard bands. Light still stops on solid stone and still spills through an open door. Unlit unexplored floor stays near-black navy. A seen room you are lighting should feel filled, not a hard disk on black.
2. Zoom out (`-` on desktop, including 0.25x). Unexplored rooms stay black. The lit pool stays with the player.
3. Pause, GL LIGHT **OFF**. The frame should jump back to the old Canvas lightmap (banded shadow, tighter gradient). ON / AUTO returns to the soft look on High.
4. On a githack (or localhost) build, the sun button at the top left opens Lighting (Dev) while you are playing. Scroll the card to the bottom. Seen and Void are color pickers. Rays, bite, and the outline update the visibility polygon as you move. The public GitHub Pages build has no sun button.
5. Lighting **Low**. Path stays Canvas even if GL LIGHT is ON. Phone default is this until High is chosen. Bloom dials still multiply the weaker Low preset.
6. iPhone Safari: set High + AUTO. Walk with a torch, a brazier, a fire pit, and a solved prism if one is handy. Confirm flames, eyes, and HUD sit above the dark, and that a reload with WebGL blocked (or Low) still plays.
7. Resize the window and rotate the phone. No stretched light, no permanent black frame.
